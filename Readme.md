# 🏡 California Housing Price Prediction

An end-to-end Machine Learning project that predicts California housing prices using regression models and Scikit-learn pipelines. The project covers data preprocessing, feature engineering, model training, evaluation, and deployment-ready prediction.

---

# 📌 Project Overview

This project predicts the median house value in California based on housing-related features such as:

- Median Income
- House Age
- Average Rooms
- Average Bedrooms
- Population
- Average Occupancy
- Latitude
- Longitude

The complete machine learning workflow is implemented from data preprocessing to model serialization.

# ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/mohitkhangar/California-Housing-Price-Prediction.git
```

Move into the project directory:

```bash
cd California-Housing-Price-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

